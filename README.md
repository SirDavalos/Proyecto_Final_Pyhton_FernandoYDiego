# Proyecto_Final_Pyhton_FernandoYDiego
Este proyecto trata de un juego de "Elegir tu propia aventura" usando python. El juego se basa en la historia de "Assasins Creed 4: Black GFag"

# Requerimientos
Librerias necesarias:
 * **windows-curses**
 * **questionary**

Se pueden instalar todo lo necesario con el siguiente comano

> pip install -r  requirement.txt

# Ejecucion
El proyecto no puede ejecutarse dentro de pycharm.
Para ejecutar el juego, se  hacer lo siguente:
* Abrir una terminal
* Navegar hasta la carpeta del proyecto.
* Ejecutar el siguiente comando
> python Main.py
